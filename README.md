# Customer Churn Analysis Dashboard

## Business Problem
The company faced increasing customer churn and required insights into customer behavior, contract patterns, and retention trends to improve customer loyalty.

## Objective
Develop an interactive Power BI dashboard to:
- Monitor churn trends
- Analyze customer behavior
- Identify churn drivers
- Provide retention recommendations

## Tools Used
- Power BI
- Excel
- Power Query
- DAX

## Key KPIs
- Total Customers
- Churn Rate %
- Retained Customers
- Monthly Charges
- Customer Tenure

## Key Insights
- Month-to-month contract customers showed highest churn rates.
- Customers with shorter tenure were more likely to leave.
- Electronic check payment users had higher churn probability.

## Business Recommendations
- Promote yearly subscription plans.
- Improve onboarding experience for new customers.
- Introduce loyalty rewards to improve retention.

## Project Outcome
The dashboard helps businesses monitor churn behavior and make data-driven retention decisions through interactive reporting and visual analysis.
